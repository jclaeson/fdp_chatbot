FedEx API Assistant

Chrome Extension for Quick Access to FedEx API Documentation

  • Quick access to FedEx API documentation
  • Instant API assistant chat
  • Code examples and best practices
  • Search FedEx Developer Portal

Installation Instructions

  1. Click the Download Extension button above
  2. Save the fedex-api-assistant.zip file to your computer
  3. Extract the ZIP file to a folder
  4. Open Chrome and go to chrome://extensions/
  5. Enable Developer mode (toggle in top right)
  6. Click Load unpacked
  7. Select the extracted folder
  8. The extension icon will appear in your toolbar!
